# موقع الخطة التشغيلية 1448هـ

الموقع مستقل ويعمل دون اتصال بالإنترنت.

## التشغيل السريع

افتح ملف `index.html` مباشرة في المتصفح.

ولتشغيله عبر خادم محلي من المجلد الأب:

```powershell
python -m http.server 8000 --directory site
```

ثم افتح: `http://127.0.0.1:8000`
